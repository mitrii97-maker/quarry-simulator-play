# Visual asset provenance

The local 1024-pixel JPG maps are optimized derivatives of these CC0/public-domain PBR sets distributed by Meshy. Each directory includes the downloaded license notice.

- `gravel/`: ambientCG **Gravel035**, Grey riverbed gravel. https://www.meshy.ai/textures/stone/grey-riverbed-gravel ; https://ambientcg.com/view?id=Gravel035
- `rock/`: ambientCG **Rock060**, Brown rock face. https://www.meshy.ai/textures/stone/brown-rock-face ; https://ambientcg.com/view?id=Rock060
- `snow/`: ambientCG **Snow010A**, Clean fresh snow. https://www.meshy.ai/textures/grass/clean-fresh-snow ; https://ambientcg.com/view?id=Snow010A

The excavator, trucks, rigged linkages, extra equipment details and weather are original procedural geometry/code. No downloaded vehicle mesh is included. Three.js license is retained in `THREE-LICENSE.txt`.
